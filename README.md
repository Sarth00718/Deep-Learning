## Quick Start Guide

1. **Clone the repository:**  
   ```bash
   git clone https://github.com/Sarth00718/Deep-Learning.git
   ```  
2. **Navigate to the project directory:**  
   ```bash
   cd Deep-Learning
   ```  
3. **Install dependencies:**  
   ```bash
   pip install -r requirements.txt
   ```  
4. **Run the main script:**  
   ```bash
   python main.py
   ```
